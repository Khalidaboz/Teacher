# 📚 Math Tutor Management System (Whacka App)

تطبيق متكامل لإدارة الدروس الخصوصية لمادة الرياضيات باللغة الإنجليزية (معلم وطالب)، مصمم خصيصاً لتنظيم الحصص، متابعة الحضور والواجبات، نظام النقاط التنافسي (Gamification)، والميزانية والإيرادات.

---

## 🚀 المميزات الرئيسية
* **بوابتان منفصلتان:**
  * **بوابة المعلم:** إدارة الطلاب، جدولة الحصص (أسبوعية متكررة / طارئة)، تسجيل الغياب والحضور، حساب الإيرادات والمصروفات الشخصية، وتصدير تقارير PDF المباشرة.
  * **بوابة الطالب:** متابعة المواعيد، الواجبات، ورصيد النقاط والمستويات.
* **إدارة مرنة للحصص:** دعم الحصص الفردية والمجموعات، مع تحديد مكان الحصة (منزل 🏠، سنتر 🏢، أو أونلاين 💻).
* **دعم متعدد المنصات:** مبني باستخدام **Flutter** ليعمل بكفاءة كتطبيق موبايل (APK) على أجهزة الأندرويد.
